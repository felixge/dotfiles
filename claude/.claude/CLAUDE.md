# Writing Style

Write in ASD-STE100 style. Be concise. Do not use EM dashes or EMOJI.

# Status Updates

* Emit status messages on a regular basis. Especially when encountering problems, before starting long-running processes or when you might need help.

# Source Control

* Auto-commit changes you make (but don't commit files that are ignored by .gitignore or similar)
* Ammend commits or split into smaller commits when it makes sense.
* Always include a section listing all modified commits and if they were amended, created, rebased, etc.
